# @wearables-ui-toolkit/androidx-shapes

This package provides TypeScript shape geometry used by UI Toolkit for smooth rounded rectangles, rounded polygons, card tails, and tooltip arrows. Most applications receive it transitively through `@wearables-ui-toolkit/mrbd`.
